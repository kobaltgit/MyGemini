# [НАЧАЛО РАЗДЕЛА: API_KEY]

### 🔑 Как получить и установить API-ключ Google

API-ключ — это ваш персональный бесплатный ключ доступа к нейросетям Google Gemini. Бот работает по модели **BYOK (Bring Your Own Key)**: запросы отправляются напрямую к Google от вашего имени, а бот шифрует и надёжно хранит ключ в базе данных, никогда не передавая его третьим лицам.

#### ❗ Важное замечание для пользователей из регионов с ограничениями

Доступ к Google AI Studio может быть ограничен в зависимости от вашего региона. Если при переходе по ссылкам сайт не открывается или выдает ошибку доступности региона:
* **Используйте сетевые средства обхода ограничений (VPN / прокси)** или соответствующие расширения для браузера (Chrome, Firefox и др.).
* Рекомендуется выбирать локации: США, страны Европы (Германия, Нидерланды и др.).
* После включения обновите страницу Google AI Studio. Сам бот работает на сервере без ограничений — VPN нужен только один раз для выпуска ключа в браузере.

#### Пошаговая инструкция получения ключа

1. **Зайдите в Google AI Studio:**
   Перейдите по ссылке: [https://aistudio.google.com/](https://aistudio.google.com/) и авторизуйтесь под своим Google-аккаунтом.

2. **Перейдите в раздел API-ключей:**
   В левом меню нажмите **"Get API key"** или перейдите по прямой ссылке:
   👉 [https://aistudio.google.com/apikey](https://aistudio.google.com/apikey)

3. **Создайте ключ:**
   Нажмите кнопку **"Create API key"** (или "Create API key in new project").

   ![Создание ключа](https://i.ibb.co/hJm9HHhM/Screenshot-of-Chat-Google-AI-Studio.jpg)

4. **Скопируйте полученный ключ:**
   В появившемся окне нажмите значок копирования (ключ начинается на `AIzaSy...`).

   ![Копирование ключа](https://i.ibb.co/Kc0cbTmL/Screenshot-of-Get-API-key-Google-AI-Studio.jpg)

5. **Установите ключ в боте:**
   Вы можете сделать это любым удобным способом:
   * **Самый быстрый способ:** просто отправьте скопированный ключ прямо в чат боту. Бот мгновенно удалит ваше сообщение из чата ради безопасности, зашифрует ключ и сохранит в вашем профиле.
   * **Через команду:** отправьте команду `/set_api_key` и введите ключ.
   * **Через меню настроек:** откройте `/settings` (или кнопку «⚙️ Настройки») ➔ нажмите «🔑 Управление API ключом».

После успешной валидации бот уведомит вас, и все возможности будут открыты!

# [НАЧАЛО РАЗДЕЛА: FEATURES]

### 🚀 Возможности и инструментарий бота

MyGemini — многофункциональный интеллектуальный ассистент на базе моделей Google Gemini последнего поколения.

#### 🧠 Потоковый чат в реальном времени (Streaming)
* Ответы выводятся постепенно, слово за словом, без томительного ожидания завершения ответа.
* Во время формирования ответа отображается кнопка **[⏹️ Стоп]**, позволяющая прервать генерацию в любой момент.
* В шапке или HUD отображается точное время генерации и число затраченных токенов (например: `⚡ 4.1s • 📊 1790 токенов`).

#### ⚡ Быстрые действия под каждым ответом (Quick Actions)
Под готовым ответом бота доступны интерактивные кнопки:
* **🔄 Еще раз:** перегенерировать ответ модели заново с теми же вводными данными.
* **↩️ Откатить шаг:** отменить последний ход беседы (удаляет последний ответ бота и ваш запрос, очищая контекст).
* **🐍 В песочницу:** быстрый переход в режим изолированной песочницы Python для решения расчетных задач.
* **📥 Экспорт в .md:** мгновенно выгрузить весь текущий диалог в чистый файл Markdown (`dialog_X.md`).

#### 🐍 Изолированная песочница Python (Code Execution)
* Физическое выполнение программного кода в изолированной облачной среде Google.
* Обеспечивает **100% математическую точность** без галлюцинаций: факториалы, расчет сложных формул, комбинаторика, точный подсчет символов, букв и слов в текстах, статистика, парсинг данных.
* **Два варианта использования:**
  1. Глобальное включение в `⚙️ Настройки` (песочница будет доступна модели при любых вопросах, требующих вычислений).
  2. Выделенный режим по кнопке `[🐍 В песочницу]` — запрос выполняется на чистом листе, без помех из истории диалога, а результат сохраняется в память беседы.

#### 🌐 Поиск Google в реальном времени (Google Search Grounding)
* Включение веб-поиска в `⚙️ Настройки ➔ 🌐 Google Поиск`.
* Модель ищет актуальную информацию в интернете: последние мировые новости, текущие курсы валют, спортивные события, техническую документацию.

#### 🧠 Настройка глубины размышлений (Thinking Budget)
* Для думающих моделей Gemini 2.5/3 доступна регулировка бюджета «мыслей»:
  * **⚡ Мгновенно (0):** максимальная скорость без расширенных размышлений.
  * **⚖️ Баланс (1024 токена):** оптимальный баланс скорости и аналитической проработки (по умолчанию).
  * **🔬 Глубокий анализ (4096 токенов):** предельная глубина логики для сложнейшего кода и комплексных задач.

#### 🖼️ Мультимодальный анализ изображений
* Отправьте боту фотографию или скриншот.
* Добавьте текстовую подпись с задачей (например: «Распознай текст на фото», «Реши задачу на доске», «Опиши состав блюда»).

#### 🎙️ Голосовые сообщения
* Отправляйте аудиосообщения — бот напрямую прослушивает голос, извлекает смысл и формирует структурированный ответ.

#### 🗂️ Менеджер диалогов (`/dialogs`)
* Создание неограниченного числа независимых диалогов (например: «Работа», «Кодинг», «Учеба»).
* Контексты разных диалогов изолированы и не перемешиваются.
* Возможность переключения, переименования, удаления диалогов и экспорта в `.md`.

#### 📜 История сообщений по датам (`/history`)
* Удобный календарь с навигацией по месяцам.
* Просмотр всей переписки в активном диалоге за любой выбранный день в виде раскрывающихся цитат.

#### 📊 Статистика расходов (`/usage`)
* Детальный мониторинг расхода токенов за сегодня и за текущий календарный месяц.
* Автоматический расчет ориентировочной стоимости в USD по официальным тарифам Google.

#### 👤 Личный кабинет (`/account`)
* Ваш персональный профиль, счетчик сообщений, звание, статус API-ключа и тематический анализ наиболее частых вопросов.

#### 🇷🇺/🇬🇧 Быстрый переводчик (`/translate`)
* Удобный интерфейс для перевода текстов на популярные мировые языки.

#### 📋 Справочник команд бота
* `/start` — Перезапуск бота и инициализация сессии
* `/help` — Краткая справка по возможностям
* `/help_guide` (или `/guide`) — Полное подробное руководство
* `/apikey_info` (или `/key_info`) — Инструкция по созданию API-ключа
* `/set_api_key` — Установить или обновить API-ключ
* `/settings` — Меню настроек моделей, стилей и функций
* `/dialogs` — Управление диалогами
* `/history` — Просмотр истории переписки по календарю
* `/usage` — Статистика использования токенов и расходов
* `/translate` — Встроенный переводчик
* `/account` (или `/profile`) — Личный кабинет
* `/reset` — Очистить контекст текущего диалога
* `/feedback` — Отправить сообщение или отзыв разработчикам

# [НАЧАЛО РАЗДЕЛА: SETTINGS]

### ⚙️ Меню настроек (`/settings`)

В меню настроек вы можете адаптировать MyGemini под свои рабочие процессы.

#### 🧠 Выбор нейросетевой модели
* **gemini-2.5-flash:** Флагманская быстрая модель с поддержкой инструментов, размышлений и мультимодальности (по умолчанию).
* **gemini-2.5-pro:** Самая мощная модель для сложных интеллектуальных задач, глубокого рефакторинга и научных расчетов.
* **gemini-2.5-flash-lite:** Ультрабыстрая модель с автоматическим резервным включением при исчерпании квот.
* **gemini-3.1-flash-lite / gemini-3-flash / gemini-3-pro:** Семейство моделей нового поколения с передовой архитектурой.
* **gemini-1.5-flash / gemini-1.5-pro:** Классические модели предыдущего поколения для сохранения привычного поведения.

#### 🎭 Персона ассистента
Выбор профессиональной роли кардинально меняет логику и экспертизу ответов:
* **🤖 Обычный ассистент** — универсальный помощник на каждый день.
* **🐍 Senior Python Developer** — архитектура, чистый код, асинхронность, рефакторинг.
* **📊 Data Scientist & ML** — анализ данных, статистика, алгоритмы машинного обучения.
* **✍️ Экспертный копирайтер** — живые тексты, статьи, посты без канцеляризмов.
* **💼 Бизнес-консультант** — стратегии, финмодели, SWOT-анализ, маркетинг.
* **🧠 Ментор по обучению** — понятные объяснения сложных тем по методу Фейнмана.

#### 👔 Стиль общения
*(Применяется при выборе роли «Обычный ассистент»)*
* **Официальный:** Деловой, строгий, академический тон.
* **Неформальный:** Дружелюбный, живой, доступный язык.
* **Краткий:** Максимально емко, по пунктам, без воды.
* **Подробный:** Развернутые объяснения с примерами и деталями.

#### 💬 Оформление шапки контекста
* **Цитата (blockquote):** Красивая расширяемая цитата Telegram с названием диалога, персоной и моделью.
* **Компактный:** Лаконичная однострочная плашка (`💬 Диалог • ⚡ Модель`).
* **Скрытый:** Полное отключение шапки, в сообщении выводится только чистый ответ.

#### 📄 Формат сообщений
* **Богатый (Rich):** Полное форматирование с интерактивными кнопками быстрых действий и строкой HUD.
* **Обычный (Plain):** Минималистичный текстовый вывод.

#### 🧠 Бюджет размышлений
* Регулировка глубины рассуждений модели (0, 1024 или 4096 токенов).

#### 🐍 Песочница Python
* Переключатель `🟢 Вкл` / `🔴 Выкл`. Позволяет модели писать и физически исполнять Python-код в реальном времени.

#### 🌐 Google Поиск
* Переключатель `🟢 Вкл` / `🔴 Выкл`. Активирует поиск актуальных данных во внешней сети Google.

#### 🌐 Язык интерфейса
* Переключение языка интерфейса и системных сообщений бота: Русский (`ru`) или English (`en`).

#### 🔑 Управление API-ключом
* Просмотр текущего статуса ключа, валидация и безопасная замена.
