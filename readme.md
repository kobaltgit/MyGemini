## 📖 Описание проекта

**MyGemini** — это высокопроизводительный, асинхронный Telegram-бот нового поколения, построенный на базе фреймворка **`aiogram 3.x`** и официального **`google-genai` SDK**. 

Бот работает по модели **BYOK (Bring Your Own Key)**: вы подключаете свой собственный бесплатный Google AI Studio API-ключ. Сервис полностью бесплатен, не взимает платы за токены, надежно шифрует ключи алгоритмом **Fernet** и обеспечивает 100% приватность диалогов.

### 🌟 Главные преимущества v2 (aiogram 3.x Modernization):
* **Официальный SDK `google-genai`**: Прямое взаимодействие с моделями семейств Gemini 2.5 и 2.0 с нативным асинхронным стримингом.
* **Плавный живой стриминг с умным троттлингом**: Ответ выводится по мере генерации в реальном времени с возможностью прерывания генерации кнопкой `[⏹️ Стоп]`.
* **Песочница Python (Code Execution)**: Реальное выполнение Python-кода в изолированной облачной среде Google Cloud для точных вычислений, симуляций, хэширования и работы с данными без галлюцинаций.
* **Многоуровневый каскадный фолбэк при 429 (Quota)**: Автоматическое мягкое переключение на рабочие модели с сохранением инструментов поиска и кода при исчерпании бесплатных квот.
* **Полная панель администратора**: Статистика активности, список пользователей, карточки по ID, блокировка, сброс ключей, массовая рассылка и выгрузка в CSV (UTF-8 BOM).

## 🚀 Основные возможности

### 👤 Для пользователей

1. **Модель BYOK и криптографическая безопасность:**
   * Работает с вашим персональным ключом Google AI Studio.
   * Ключи шифруются симметричным шифром Fernet перед записью в базу.
   * **Перехват ключей на лету:** если вы случайно отправите ключ `AIzaSy...` обычным сообщением в чат, бот мгновенно удалит сообщение для безопасности и надежно сохранит его.

2. **Богатый интерфейс сообщений (Rich Messages):**
   * **Шапка сообщения (Header Styles):**
     * ▎ *Открытая цитата (Blockquote)*
     * 🔽 *Сворачивание под спойлер (Expandable spoiler)*
     * 🚫 *Скрытый режим*
   * **Метрики ответа в реальном времени:** точное время генерации и подсчёт токенов (`⚡ 2.4s • 📊 1250 токенов`).
   * **Форматы сообщений:** переключение между Telegram HTML Rich и классическим Markdown.

3. **Панель быстрых действий под ответом:**
   * `[🔄 Еще раз]` — мгновенная перегенерация последнего ответа с удалением предыдущей версии.
   * `[↩️ Откатить шаг]` — удаление пары реплик (вопрос + ответ) из контекста диалога в один клик.
   * `[🐍 В песочницу]` — запуск выделенного режима чистых вычислений на Python.
   * `[📥 Экспорт в .md]` — выгрузка диалога в чистый GitHub Markdown-файл.

4. **🐍 Песочница Python (Google Cloud Code Execution):**
   * Включение тумблером в Настройках или запуск в 1 клик по кнопке `[🐍 В песочницу]`.
   * **Изолированный режим:** задача решается с чистого листа без шума старых сообщений, гарантируя точный запуск кода и честный консольный вывод.
   * Результат и формулы автоматически фиксируются в историю активного диалога.

5. **🧠 Управление размышлениями (Thinking Budget):**
   * Тонкая настройка бюджета размышлений для моделей `gemini-2.5-flash` и `gemini-2.5-pro`:
     * `⚡ Мгновенно (0)` — отключение размышлений для максимальной скорости.
     * `⚖️ Баланс (1024)` — сбалансированные мысли и качественный ответ.
     * `🔬 Глубокий анализ (4096)` — углубленное пошаговое рассуждение.

6. **Многоконтекстные диалоги:**
   * Создание неограниченного числа независимых диалогов.
   * Быстрое переключение, переименование, удаление и экспорт.

7. **Динамическая пагинация моделей из Google API:**
   * Получение полного каталога доступных моделей напрямую из Google API.
   * Удобные навигационные кнопки `[◀️]` `[📄 X / N]` `[▶️]` по 8 моделей на экран с LRU-кэшированием.
   * Приоритетное размещение флагманов: `Gemini 2.5 Flash`, `Gemini 2.5 Pro`, `Gemini 2.0 Flash`.

8. **Стили и Персоны:**
   * Выбор роли бота (программист, копирайтер, аналитик, переводчик).
   * Выбор стиля подачи ответов.

### 👑 Для администратора (`/admin`, `👑 Админ-панель`)

Полнофункциональная панель управления, оптимизированная под 100% бесплатного бота:

* **📊 Статистика активности:**
  * Всего зарегистрировано пользователей
  * Активных за 7 дней (отправляли запросы)
  * Новых пользователей за неделю
  * Число пользователей с установленным API-ключом
  * Количество заблокированных пользователей
* **👥 Список пользователей (`admin_users_list`):**
  * Цветовые маркеры: 👑 администратор, 🟢 активен (ключ есть), ⚪ без ключа, ⛔️ заблокирован.
  * Вывод Telegram ID, даты первого входа и количества сообщений.
  * Защита от переполнения лимитов Telegram (4096 символов) и экранирование спецсимволов.
* **🔍 Карточка пользователя по ID (`/user <id>` или кнопка поиска):**
  * Детальная сводка профиля, выбранная модель, стиль, язык, число сообщений.
  * `[🚫 Заблокировать / ✅ Разблокировать]` в один клик.
  * `[🔑 Сбросить API-ключ]` при компрометации.
  * `[✉️ Ответить пользователю]` (через меню или команду `/reply <id> <текст>`).
* **📥 Экспорт базы данных в CSV с UTF-8 BOM (`admin_export_csv`):**
  * Файл формируется с кодировкой `utf-8-sig` (гарантирует корректное отображение русских букв в Microsoft Excel без кракозябр).
* **📢 Массовая рассылка сообщений (`admin_broadcast`):**
  * Поддержка Telegram HTML-форматирования, предпросмотр сообщения, подтверждение перед отправкой и подробный отчет о доставке.
* **🛠 Режим обслуживания (`admin_toggle_maintenance`):**
  * Мгновенное ограничение доступа к боту для проведения технических работ с живым индикатором 🟢/🔴 на кнопке.
* **🔔 Уведомления о новых пользователях:**
  * Мгновенное информирование администратора в ЛС при первом запуске бота новым пользователем.

## ⚙️ Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/kobaltgit/MyGemini.git
cd MyGemini
```

### 2. Создание виртуального окружения
```bash
python -m venv .venv

# Для Linux / macOS:
source .venv/bin/activate

# Для Windows (PowerShell):
.venv\Scripts\Activate.ps1
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения (`.env`)
Создайте файл `.env` в корне проекта (по шаблону):
```env
# Токен вашего бота от @BotFather
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz

# Telegram ID администратора для доступа к админ-панели и уведомлениям
ADMIN_USER_ID=300051541

# Ключ симметричного шифрования (сгенерируйте Fernet.generate_key().decode())
ENCRYPTION_KEY=your_generated_fernet_key_here==

# Модель по умолчанию
GEMINI_MODEL_NAME=gemini-2.5-flash

# Ссылка на поддержку/донаты (опционально)
DONATION_URL=https://pay.example.com/donation
```

### 5. Запуск бота
```bash
python main.py
```

После старта бот сразу готов к работе. Зайдите в Telegram, нажмите `/start` и следуйте подсказкам.
