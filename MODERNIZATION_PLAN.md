## 🏛️ ГЛАВНЫЕ ПРАВИЛА И ОГРАНИЧЕНИЯ (ТАБУ)

1. **Серверное Fernet-шифрование API-ключей СОХРАНЯЕТСЯ:**
   * В базе `database/bot_database.db` ключи пользователей зашифрованы с помощью `ENCRYPTION_KEY` из `.env` через `cryptography.fernet`.
   * Это шифрование сохраняется на 100%, чтобы существующие 1 239 пользователей не потеряли свои ключи.
2. **БЕЗ клиентского Zero-Knowledge:**
   * Нет пользовательских мастер-паролей, нет солей PBKDF2, нет паролей паники. Бот открывается сразу без ввода паролей.
3. **БЕЗ векторной базы данных:**
   * Нет ChromaDB, нет Qdrant, нет эмбеддингов. Диалоги строятся по локальной истории сообщений из SQLite.
4. **БЕЗ платных подписок:**
   * Бот остается на 100% бесплатным для всех пользователей в модели BYOK (Bring Your Own Key).
5. **Безопасная разработка без удаления старого кода:**
   * Старые файлы не удаляются вплоть до полного написания, тестирования и подтверждения работы всех новых роутеров на `aiogram 3`.
6. **КАТЕГОРИЧЕСКИЙ ЗАПРЕТ НА ПЕРЕПИСЫВАНИЕ ФАЙЛОВ С НУЛЯ:**

## 📱 ГЛАВНОЕ МЕНЮ (СТРОГО СОХРАНЯЕТСЯ ФОРМАТ 3×3 ИЗ ЭТАЛОНА)

Нижняя панель Telegram сохраняется **строго в исходном боевом виде (3 ряда по 3 кнопки)**:

```text
[👑 Админ-панель]   [🗂️ Диалоги]       [👤 Личный кабинет]
[📊 Расходы]        [⚙️ Настройки]      [🇷🇺 Перевести]
[📜 История]        [❓ Помощь]         [🔄 Сброс]
```
*(Для пользователей без прав администратора отображаются те же 8 кнопок в 3 рядах без кнопки админа).*

### Сохраняемый боевой функционал всех 9 кнопок:
1. **`👑 Админ-панель` (`/admin`)**: доступна только для `ADMIN_USER_ID`: статистика пользователей, переключатель режима ТО, рассылка сообщений, экспорт пользователей в CSV с UTF-8 BOM, управление пользователем `/user <id>` (блокировка, сброс ключа).
2. **`🗂️ Диалоги` (`/dialogs`)**: список диалогов с отметкой активного `✅`, переключение, создание нового, переименование, удаление.
3. **`👤 Личный кабинет` (`/account`, `/profile`)**: звание пользователя, количество сообщений, дней с ботом, текущая персона, статус API-ключа и автоматический анализ тем общения диалога (`features/personal_account.py`).
4. **`📊 Расходы` (`/usage`)**: подсчет токенов за сегодня и за текущий месяц (`get_token_usage_by_period`) + расчет примерной стоимости в долларах США на основе официальных расценок моделей (`TOKEN_PRICING`).
5. **`⚙️ Настройки` (`/settings`)**: выбор модели, персоны, стиля общения, языка, управление API-ключом + **новые настройки из v2** (песочница Python, бюджет размышлений, стиль шапки, формат сообщений).
6. **`🇷🇺 Перевести` (`/translate`)**: инлайн-выбор языка перевода (`TRANSLATE_LANGUAGES`: английский, немецкий, французский, испанский, итальянский, китайский, японский, русский) -> FSM-ожидание текста -> мгновенный перевод через Gemini.
7. **`📜 История` (`/history`)**: интерактивный инлайн-календарь с днями месяца -> выбор конкретной даты -> вывод истории сообщений пользователя за выбранный день.
8. **`❓ Помощь` (`/help`)**: справочный раздел по командам и возможностям бота, кнопка поддержки автора донатом (`DONATION_URL`), команда отправки отзыва/репорта разработчику (`/feedback`).
9. **`🔄 Сброс` (`/reset`)**: мгновенная очистка контекста текущего диалога без удаления самого диалога с подтверждением пользователю.

## 🚀 ВСЕ ИННОВАЦИИ ДЛЯ ВНЕДРЕНИЯ ИЗ MyGemini_Zero_v2

### 1. Шапка контекста диалога и её настройки (как в MyGemini_Zero_v2)
* **Структура и динамическое наполнение шапки:**
  * Обычный режим:
    ```text
    > 💬 Диалог: Название диалога
    > 🎭 Персона: Эксперт по Python
    > ⚡ Модель: gemini-2.5-flash
    > ⚡ 2.4s • 📊 850 токенов
    ```
  * При активной песочнице Python:
    ```text
    > 💬 Диалог: Название диалога
    > 🐍 Режим: Изолированная песочница Python
    > ⚡ Модель: gemini-2.5-flash
    > ⚡ 3.1s • 📊 1 120 токенов
    ```
* **Настройки отображения шапки в «⚙️ Настройки» (`header_style`):**
  * `▎ Открытая цитата (Вариант 1)` (`blockquote`, по умолчанию) — нативная вертикальная плашка цитирования Telegram со аккуратным выравниванием строк;
  * `🔽 Сворачивать под спойлер` (`expandable`) — нативная сворачиваемая цитата с плашкой `💬 {dialog_title} • ⚡ {model_id}` (по клику разворачивается полное инфо);
  * `🚫 Скрыть шапку` (`hidden`) — вывод чистого ответа модели без технической шапки (максимальный минимализм).
* **Настройки формата вывода текста (`message_format`):**
  * `⚡ Формат: Rich (10.1+)` — продвинутый HTML через `tg-rich-converter` (KaTeX формулы в читаемый Unicode, моноширинные таблицы в `<pre>`, размышления `<thought>` в спойлере);
  * `📝 Классический (Markdown)` — стандартная разметка Telegram Markdown.
* **Слой хранения:** авто-миграция колонок `header_style` (дефолт `'blockquote'`) и `message_format` (дефолт `'rich'`) в таблице `users` в `database/bot_database.db`.

### 2. Переход на современный стек `aiogram 3.x`
* Модульные роутеры (`Router`), чистые FSM-состояния (`StatesGroup`).
* Middleware (проверка блокировки `is_blocked`, режим техобслуживания `maintenance_mode`, глобальный перехват ошибок).
* Отказ от устаревшего Telebot (`AsyncTeleBot`).

### 3. Официальный SDK `google-genai >= 1.0.0` и живой стриминг
* Асинхронный стриминг `client.aio.models.generate_content_stream(...)` вместо монолитного `aiohttp` запроса.
* Плавный вывод ответа в реальном времени через интеллектуальный троттлер сообщений Telegram.
* Поддержка новейших моделей семейства Gemini 2.5 (Flash, Pro, Flash-Lite).

### 4. Форматирование текста через библиотеку `tg-rich-converter`
* Прямой импорт из PyPI:
  ```python
  from tg_rich_converter import to_rich, split_rich_message
  ```
* Математические формулы KaTeX / LaTeX ($x^2$, $\frac{a}{b}$, $\sqrt{x}$) автоматически транслируются в читаемый Unicode.
* Markdown-таблицы конвертируются в моноширинные аккуратные `<pre>` блоки.
* Блоки размышлений модели `<thought>` / `thinking` прячутся в спойлеры `<blockquote expandable>`.
* Интеллектуальное разбиение длинных сообщений до 32 768 символов (`split_rich_message`) с гарантией целостности HTML-тегов.

### 5. Интерактивный HUD и быстрые действия под ответом
* **HUD в шапке ответа:** `⚡ 2.4s • 📊 850 токенов` (время генерации + токены из `usage_metadata`).
* **Во время стриминга:** кнопка `[⏹️ Стоп]` (мгновенное прерывание потока).
* **Под завершенным ответом:**
  * `[🔄 Еще раз]` — регенерация последнего ответа модели;
  * `[↩️ Откатить шаг]` — удаление последней пары сообщений (вопрос + ответ) из контекста диалога;
  * `[📥 Экспорт в .md]` — мгновенное скачивание диалога в виде красивого GitHub Markdown файла.

### 6. Управление бюджетом размышлений (Thinking Budget)
* Выбор глубины рассуждений в «Настройках»:
  * `0` — ⚡ Мгновенно (Instant, без рассуждений)
  * `1024` — ⚖️ Баланс (по умолчанию / Balanced)
  * `4096` — 🔬 Глубокий анализ (для сложного кода, логики и математики)
* Сохранение выбора пользователя в базе данных (`users.thinking_budget`).

### 7. Изолированная песочница Python (Code Execution)
* Тумблер в «Настройках»: `🐍 Песочница Python: <🟢 Вкл / 🔴 Выкл>`.
* Передача инструмента `types.Tool(code_execution=types.ToolCodeExecution())`.
* Модель сама пишет и выполняет Python-код, выводя блок `[Вывод песочницы / Output]`.
* Сохранение состояния в базе данных (`users.enable_code_execution`).

### 8. Продвинутый Google Search с источниками
* Интеграция `types.Tool(google_search=types.GoogleSearch())` с выводом ссылок на источники (grounding metadata).
* Авто-отключение поиска для моделей, где он не поддерживается (`KNOWN_NO_SEARCH_MODELS`).

### 9. Авто-fallback на `gemini-2.5-flash-lite` при ошибках квот (429)
* При исчерпании квоты на Pro/Flash модели бот автоматически переключается на облегченную `gemini-2.5-flash-lite`, выводя уведомление и не прерывая диалог.

### 10. Расширенная карта дружелюбных ошибок Google API
* Корректная обработка 503 (высокая нагрузка на серверах Google), фильтров безопасности (Safety), авторских прав (Recitation) и пустых ответов.

### 11. Мгновенная защита от утечки API-ключа в чате
* Моментальный перехват и авто-удаление случайно отправленного ключа `AIzaSy...` из чата за 0.25 сек с авто-шифрованием и сохранением в профиль пользователя.

### 12. Promo Engine (Ненавязчивая промо-система)
* Модуль `services/promo_service.py` с реестром проектов автора.
* Мягкое нативное продвижение старшего брата **`MyGemini Zero`** (`@mgemz_bot`) для тех, кому нужно сквозное шифрование и RAG-память.
* Слоты показа: в справке `/help`, в подвале экспортируемых диалогов `.md`, в настройках и в витрине `/projects`.
* Легкое подключение новых проектов автора по мере готовности.

### 13. Тотальное покрытие тестами (`pytest` / `pytest-asyncio`)
* Полноценная тестовая инфраструктура в каталоге `tests/` с обязательным правилом: **100% тестов должны проходить успешно перед любым слиянием в `main`**.
